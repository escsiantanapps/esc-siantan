# Panduan Pengguna — Volunteer & PKS

Panduan ini untuk **Volunteer** (pelayan) dan **PKS** (Pemimpin Komsel).
Volunteer & PKS memiliki **semua fitur Jemaat** (lihat *Panduan Jemaat*) plus
fitur tambahan di bawah ini.

---

## A. Untuk Volunteer

### 1. Tugas Pelayanan
- Tab **Tugas** menampilkan tugas sesuai **ministry** Anda (selain tugas umum).
- Isi formulir tugas dan **Kirim Jawaban**. Progres mingguan/bulanan terlihat
  di tiap kartu tugas (mis. "2/4 terpenuhi").
- Beberapa tugas memiliki **jam buka/tutup** dan **hari aktif** tertentu.

### 2. Absensi via Scan
- Gunakan tombol **Scan** untuk memindai QR kehadiran (kelas/event) yang Anda
  layani.

> Catatan: fitur **absensi ketepatan waktu pelayanan Minggu** (rekap hadir tepat
> waktu / telat) sedang direncanakan — lihat dokumen PRD bila sudah tersedia.

---

## B. Untuk PKS (Pemimpin Komsel)

PKS dapat memimpin **satu atau beberapa komsel**. Akses PKS muncul setelah admin
menetapkan Anda sebagai pemimpin komsel.

### 1. Membuka Dashboard PKS
- Dari aplikasi, buka menu/tab **PKS** (atau pindah panel bila Anda juga admin).
- Jika memimpin lebih dari satu komsel, pilih komsel dari dropdown di atas.

### 2. Mencatat Absensi Komsel
1. Di Dashboard PKS → tab/bagian **Absensi**.
2. Untuk tiap anggota, pilih status: **Hadir / Tidak Hadir / Izin**.
3. Tambahkan **catatan doa** bila perlu.
4. Ketuk **Simpan Absensi**. Riwayat absensi mingguan tersimpan dan bisa dilihat.

### 3. Memantau Anggota
- Dashboard menampilkan daftar **anggota komsel** Anda.
- Tersedia ringkasan **evaluasi tugas** tiap anggota (Terpenuhi / Proses /
  Kosong) untuk membantu pendampingan.

### 4. Privasi Data
PKS hanya dapat melihat data **anggota dari komsel yang Anda pimpin** — bukan
seluruh jemaat. Data sensitif jemaat lain tidak dapat diakses.

---

## Tips
- Pastikan koneksi internet aktif saat menyimpan absensi/jawaban.
- Bila menyimpan absensi gagal, periksa kembali apakah Anda masih terdaftar
  sebagai pemimpin komsel tersebut (hubungi admin bila perlu).
